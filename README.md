# Enterprise Active Directory Security & File Server Hardening Lab

## Overview
This project demonstrates a secure Active Directory domain environment with enterprise file server hardening and ransomware prevention controls.

## Lab Setup
- SYS1: Domain Controller (Windows Server 2012)
- SYS2: Member Server + File Server
- Domain: local.com

## Implementations
- Department OUs (HR, Sales, IT)
- Secure file sharing with NTFS permissions
- Home Folder deployment
- Group Policy hardening (USB block, CMD restriction)
- FSRM quotas and file screening
